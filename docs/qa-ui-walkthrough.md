# 갈라 UI 워크스루 — 버튼·기능 전수 점검표

사장님이 불러준 목록을 표로 옮기고, **코드에서 실제 버튼 인벤토리를 뽑아 대조**해
빠진 화면·빠진 버튼·빠진 테스트를 채웠다. (2026-09-09 작성)

- 기준 코드: `~/Documents/GitHub/galla-frontend` @ `1c88c2f06` · version `0905120`
- 뽑는 법: 루트 HTML 68개의 `<button>`·`aria-label`·`data-target` + 각 화면 전용 JS의 템플릿 버튼
  (`nav.js`·`friend.js` 같은 공용 스크립트는 제외해야 화면별로 갈린다)
- **이 문서는 '눌러볼 목록'이다.** 서버·DB 검증 결과는 [`qa-checklist.md`](qa-checklist.md) 에 있고,
  현황판은 `python3 scripts/qa-board.py` 로 만든다. 중복 노동을 막으려고 §7 에 '이미 확인된 것'을 모아뒀다.

상태 표기: `⬜` 안 해봄 · `✅` 눌러서 동작 확인 · `🔶` 되는데 이상함(메모 필수) · `❌` 안 됨 · `⛔` 막힘(사유)

---

## 0. 먼저 — 이 목록으로 QA 할 때의 규칙

1. **로그인 계정을 적는다.** 심사계정(appreview@galla.im)인지 사장님 계정인지에 따라 보이는 게 다르다.
   게스트(비로그인)로도 한 번 돈다 — 로그인 유도가 제대로 뜨는지가 절반이다.
2. **웹·iOS·AOS 를 따로 센다.** 같은 버튼이 앱에서만 죽은 사고가 반복됐다
   (패스키 버튼 가림, SPA 여백 증발, 맛집 탭 4종).
3. **"눌러서 반응이 있었다"로 ✅ 하지 않는다.** 결과가 DB·화면에 남았는지까지 본다.
   과거 감사에서 `el.click()` 은 히트테스트를 건너뛰어 **덮여 있어도 통과**로 나왔다.
4. 안 되는 걸 찾으면 **재현 순서와 실측 숫자**를 메모 칸에 적는다.

### 7-7. 여행 탭
"모든 버튼" 이라고만 적혀 있어 **화면이 셋이라는 걸 짚어둔다** —
`travel-place`(여행지 상세) · `travel-vs`(대결) · `travel-creator`(채널).

상세: 난장 연결 열기 · 액션바 · 댓글·대댓글.

## 9. 이번에 요청된 기능 추가

| # | 요청 | 어디 | 상태 |
|---|---|---|---|
| 9-1 | 핫트렌드에 **뜨는 숏판 · 뜨는 롱판** 섹션 추가 | 트렌드 핫트렌드 탭 | ✅ 구현 (2026-09-09) |

**9-1** — `posts` 를 `kind` 로 갈라 `hot_score` 우선·최신 폴백으로 12개씩. 다른 선반과 같은 규칙이다.

**9-2** — 저장 표는 전부 이미 있었다: `post_bookmarks`·`food_saves`·`travel_saves`.
숏판·롱판은 같은 표를 `kind` 로 나눠 두 탭으로 낸다. 맛집은 전용 문서가 없어 트렌드 맛집 탭의
상세 시트를 연다 — 이걸 위해 `GALLA_openFoodPlace` 를 노출하고, **앱에서 파라미터가 버려지던
라우터 구멍**(`navTo("search", params)` 이 params 를 통째로 버렸다)을 같이 막았다.

**9-3** — 액션바에 갈비스 버튼이 **둘**이었다(`.galvis-btn` + `#plazaGalvisBtn`). 아이콘도 동작도 같다.

**남은 확인** — 각 화면의 저장 버튼이 실제로 그 표에 행을 넣는지는 §2-2-6 / §7-6 에서 눌러 확인한다.

## 11. 버튼 말고 **반드시 같이 볼 것**

버튼만 누르면 놓치는 것들이다. 실제로 여기서 결함이 더 많이 나왔다.

### 11-1. 상태·경계
- **빈 상태**: 콘텐츠 0개일 때 각 탭의 안내 문구(숏판·롱판은 지금 실제로 0행이다)
- **로그아웃/게스트**: 쓰기 버튼을 누르면 로그인 유도가 뜨는가, 읽기는 어디까지 되는가
- **정지(밴) 계정**: 쓰기 전부 차단되는가 (0901 에 **투표·신고·팔로우·예측댓글·뉴스댓글**이 뚫려 있어 막았다)
- **긴 텍스트·이모지**: 제목 200자·본문 5,000자·이모지 도배를 넣어 레이아웃이 버티는가
  (운영 데이터 최장이 56자라 실사용으로는 검증이 안 된다)
- **느린 네트워크·오프라인**: 로딩 표시, 실패 문구, `/offline` 폴백
- **뒤로가기**: 하드웨어 뒤로(AOS)·스와이프 뒤로(iOS)로 스택이 꼬이지 않는가
- **재방문**: 같은 화면을 두 번째 열었을 때도 초기화가 도는가(SPA 어댑터 없는 페이지에서 사고 이력)

### 11-2. 돈·권한이 걸린 자리 (틀리면 손해가 남는다)
- GP·GC **차감과 환불이 같은 지갑**인가 (0902 에 스티커가 GC 깎고 GP 로 환불하던 것 수정)
- 실패했을 때 **환불이 실제로 들어오는가** (창작 대행·스티커·가챠)
- 하루 상한(제보 3회·미션·출석·가챠)이 서버에서 강제되는가
- 남의 글 수정·삭제가 막히는가, 내 글은 되는가

### 11-3. 공유·유입
- 각 화면의 공유 링크가 **카톡·X 에서 미리보기로 뜨는가**
  (일반 페이지에 OG 가 없던 것은 0902 에 기본 카드로 메움)
- 딥링크(`im.galla.app://`)로 열었을 때 해당 화면으로 가는가
- 초대 링크(`?ref=`)로 들어온 사람에게 보상이 붙는가

### 11-4. 안전
- 위기 문구를 갈비스에 보내면 **상담카드(109·1577-0199)** 가 뜨는가
- 신고 → 관리자에게 알림 → 처리까지 도는가
- 유령권으로 익명이 됐을 때 프로필 추적이 정말 막히는가
