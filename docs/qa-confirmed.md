## 검증 방법 (다음에 또 하려면)

- **안드로이드**: `adb forward` + `webview_devtools_remote_<pid>` → CDP 로 실제 앱 안에서 JS 실행.
  클릭은 `Input.dispatchMouseEvent`(히트테스트 통과). 터치+마우스 둘 다 보내면 **두 번 눌린다**.
- **iOS**: CDP 가 없다(WebKit 인스펙터). 텍스트는 `simctl pbcopy` + 롱프레스 붙여넣기,
  한글은 `LANG=en_US.UTF-8` 필요. 파일은 `simctl addmedia` 로 사진 보관함에.
- ⚠️ 클릭 감사기는 iframe 에 **MPA 페이지**를 띄운다 → **SPA 어댑터 경로를 아예 안 지나간다.**
  #4~#8 은 감사기로 절대 못 잡는다. 표류 검사기가 따로 필요한 이유.
- ⚠️ 안전 기능(위기 상담카드)은 **payload 를 가로채서** 확인해라. 카드가 본문보다 늦게 붙어
  DOM 만 보면 "카드 없음"으로 오판한다(실제로 오판했다).
