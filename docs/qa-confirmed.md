| 결함 | 확인 근거 |
|---|---|
| 릴스 댓글창 포커스 불가 — 시트 드래그의 preventDefault 가 포커스를 죽임 | 캐럿·타이핑·DB 행 |
| 안드로이드 뒤로가기가 릴스를 못 닫음 | 시트→릴스→홈, 앱 생존 |

| 갈비스 오브가 광장 '등록' 버튼을 덮음 | elementFromPoint 정상화 + 댓글 DB 행 |
| 삐삐 안내가 DM 전체를 덮어 메시지 불가 | 히트타깃 TEXTAREA 복귀 + DM DB 행 |
| 랜덤 뽑기가 supabase 인스턴스를 잘못 잡아 전원 실패 | 콘솔 TypeError 소거 |
| 버그 제보의 앱 버전이 배포 도장이 아님 | meta[galla-ver] 로 전환 |
| **갈비스 주 대화 경로가 원가를 한 줄도 안 적음** | 배포 후 ai_spend 행 생성 확인 |
