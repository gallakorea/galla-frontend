## The Problem

Loneliness is a global epidemic — younger generations are more connected and more alone than ever. Existing "AI chatbots" are stateless tools: they answer, then forget you. Nobody is on your side.

## What We Built

GALLA is not a chatbot. It is a **relational AI** built on a proprietary memory architecture.

- **Galla Friend** — a companion AI that forms an emotional bond: it resonates with how you feel, remembers who you are across time, and *takes your side*. Not a tool — a relationship.
- **Galvis Memory Engine** — our own RAG + memory stack (profile summarization, hybrid retrieval, recall reinforcement, reflection, per-person memory, automatic consolidation). **Model-agnostic** — the moat is our data and memory layer, not any single LLM.
- **AI Creation Engine** — on-device-quality generative creation (thumbnails, video) monetized inside the product.

The moat is not the model. **The moat is the memory layer and the proprietary behavioral + opinion dataset it runs on.**
