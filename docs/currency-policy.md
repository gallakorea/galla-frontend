# 갈라 화폐 정책 (정본) — 갈라포인트(GP) · 갈라코인(GC)

> 2026-07-15 확정. 이 문서는 두 재화의 정의와 **깨서는 안 되는 불변식**의 정본이다.
> 새 기능이 재화를 만지면 반드시 이 문서와 대조할 것.

## 정의

### 갈라포인트 (GP) — 지갑 이원화 (2026-07-15 완전판 적용)
- **비현금성 놀이 재화.** 환급·환전·양도·매매 불가.
- 획득: 무료(출석·미션·활동 보상·제보·이슈 승리·가챠) + 유료 충전(`gp_charges`, 충전분은 랭킹 제외).
- **지갑 구조** (`point_balances`): `balance` = GP. `paid_balance`는 GP 판매 봉인(2026-08-11) 이후 0으로 고정된 레거시 컬럼이다.
  - **무료 GP**: 소각형 + 게임(예측·일기토) 모두 사용 가능.
  - **유료 GP**: **소각형 소비 전용**(아이템·꾸미기·가챠·부스트·밀어주기). **게임 투입 불가** —
    "유료 재화가 우연적 결과에 투입"되는 사행성 모사 고리를 구조적으로 차단.
  - 소각형 차감은 `_gp_spend()`(유료 우선 소진 → 무료), 게임 RPC는 `balance`만 참조.
- 사용처:
  - **소각형**: 아이템 상점·꾸미기(칭호/닉스타일)·가챠·부스트·진영 밀어주기 — 수령자 없음.
  - **게임 루프(유저 간 GP 이동, 무료 GP만)**: 갈라예측 파리뮤추얼, 일기토 판돈 — GP는 GP로만 이동하며 절대 현금 가치가 되지 않는다.

### 갈라코인 (GC)
- **크리에이터 후원 전용 현금성 재화.** 1 GC = 1 KRW.
- 발행: **현금(PG) 구매로만** (`gc_charges` → `gc_charge_confirm`). 보너스·이벤트·무상 지급 **절대 금지**.
- 사용처: **크리에이터 후원뿐** (`gc_donate`). 아이템·예측·게임·기타 어디에도 쓸 수 없다.
- 정산: GC 후원 → `donations`(paid, method='gc') → 분배 **플랫폼 20% / 크리에이터 50% / 기부 30%** → 크리에이터 원화 출금(`request_withdrawal` → `withdrawals`).

## 방화벽 불변식 (서버 구조로 강제, 위반 기능 금지)

1. **GP ↔ GC 상호 전환 불가.** 어느 방향의 변환 RPC도 존재하지 않으며 만들지 않는다.
2. **GC 무상 발행 금지.** 발행총량 = 유료 충전총액. `gc_audit` 뷰의 `drift`가 항상 0이어야 한다
   (issued = spent + held).
3. **출금 재원은 후원 수익(net)뿐.** `withdrawals`는 `my_creator_earnings()`(= donations.net 합)로만 검증된다.
   GP가 donations/withdrawals로 들어가는 경로를 만들지 않는다.
4. **GP는 크리에이터 수익이 될 수 없다.** GP 소비 중 유저 간 이동은 게임 루프(예측·일기토)에 한정하고,
   어떤 GP 흐름도 수익 정산(donations)으로 집계하지 않는다.
   (예: "GP 후원", "GP 슈퍼챗", "GP 선물" 기능 금지 — 유료 GP의 현금화 우회로가 된다.)
5. **GP·GC 모두 유저 간 직접 이전(선물/양도) 금지.** 환전 시장 형성 차단.
6. **UI 고지 유지**: 충전 시트·후원 시트·예측 가이드에 "GP 환급·양도 불가 / GC 후원 전용 / 상호 전환 불가" 문구.

## 재검토 트리거
- **PG 연동 직전**: ① 유료 GP의 게임(예측·일기토) 투입 차단 여부(지갑 이원화) 재결정
  ② 게임산업법·전금법(GC = 선불전자지급수단 해당 가능성, 발행잔액 규모별 등록 의무) 변호사 검토.
- **앱스토어 제출 전**: 도박 계열 문구 재점검(1차 순화 완료: 베팅→예측 참여, 잭팟→보너스 매치 등).
