## 1. 완성된 것 — 손대지 마라

- **웹 라이브**: galla.im (Cloudflare Pages 자동배포), SEO(사이트맵·IndexNow·엣지 메타주입)
- **인증**: 이메일(커스텀 SMTP Resend, `rate_limit_email_sent=30`) + 구글 + **애플** + 패스키.
  카카오는 KOE205로 제외 확정. 소셜 가입자 온보딩 게이트(닉/생년/성별/지역/약관) 작동.
- **핵심 기능**: 이슈 전투·댓글 배틀·일기토·예측(파리뮤추얼)·광장·갈라뉴스·통합검색·해시태그·
  DM/난장/삐삐·유령권·스티커/GIF·데일리미션/GP·온보딩 투어·웹푸시(8카테고리)
- **갈비스(친구 모드)**: 기억·감정·라우터·계약가드·위기안전망까지 라이브. 1차 출시 범위에 포함.
- **보안**: PII 컬럼 잠금, RLS, 크론 `CRON_SECRET` 게이트, 계정삭제 파기 감사 완료
- **운영**: 에러로거 + 버그헌터 봇(30분) + 관제센터(admin.html)
- **결제 서버 골격**: `grant_gc_topup` / `verify-iap`(ACTIVE v21, 애플 경로) / 상품표(`docs/appstore-products.md`)

## 2. 미완성 — 출시를 실제로 막는 것

### 🔴 A. 결제 — 웹·앱 **양쪽 다** 돈을 못 받는다 (최대 블로커)

| 항목 | 실측 상태 |
|---|---|
| `gc_products` | **0행** — 서버 카탈로그가 비어 IAP가 상품을 못 찾는다 |
| 앱 StoreKit/Billing | **플러그인 자체가 없음** (`galla-app/package.json`에 결제 플러그인 0개). 앱 충전 UI는 "다음 업데이트에서 열려요" 안내만 렌더 |
| 웹 PG | **미연결**. `gc_charge_begin`은 pending만 만들고 "PG 연동 예정" 문구를 띄운다 |
| 구글 검증 | 코드는 로컬에 작성됨(uncommitted). **배포된 v21은 여전히 `google_not_configured` 501** |
| 환불 회수 | `revoke_gc_topup` **DB 미적용**, `store-notify` **미배포** |
| 스토어 시크릿 | `STORE_NOTIFY_KEY`·`APPLE_IAP_SHARED_SECRET`·`APPLE_ISSUER_ID`·`APPLE_KEY_ID`·`APPLE_PRIVATE_KEY`·`APPLE_BUNDLE_ID`·`GOOGLE_SA_EMAIL`·`GOOGLE_SA_KEY` — **8개 전부 없음** |
| Apple Small Business | 가입 확인 필요. 30% 구간이면 `c1` 빼고 **전 패키지 적자**(`docs/appstore-products.md` 참조) |

→ 후원·창작 과금·아이템이 전부 GC 위에 있으므로 **이게 막히면 수익 전부가 0이다.**

### 🔴 B. iOS 배포 경로

- `App.entitlements` = `aps-environment: development`, 시크릿 `APNS_ENV=sandbox`
  → **배포 빌드에서 푸시·통화벨이 안 온다.** 심사 제출 전 둘 다 production 필수.
- **TestFlight 설치 실패 미해결** (빌드 1~4 업로드·처리·그룹배정 정상인데 "앱을 사용할 수 없음").
  케이블 직접설치는 성공 → 앱은 정상. 하지만 **외부 테스터·심사자 배포 경로가 막힌 상태**라 이걸 못 뚫으면 iOS 제출 불가.
- MARKETING_VERSION 1.0 / build 4

### 🟠 C. Google Play

- 개발자 등록·앱 생성·AAB 업로드 **전부 미착수** (`versionCode 1`, 산출물은 apk만)
- 스크린샷 3장뿐(`assets/store-screens/`: home·predict·news) — 권장 8장
- 피처그래픽 1024×500 **없음**

### 🟠 D. 반쯤 켜진 기능이 지금 그대로 노출 중

| 기능 | 상태 | 조치 |
|---|---|---|
| 육성톡/면상톡 (`dm.js` 프로필 버튼) | **플래그 없이 노출**인데 P2P 통화는 보류 상태(콜드스타트 한방향·링백 등 미해결) | 1차에선 숨긴다 |
| 라이브 난장 | `CF_CALLS_APP_ID/SECRET` 존재 → 배선은 됨, **실기기 음성 검증 미완** | 검증 후 2차 |
| 갈비스 창작 에이전트 | 2차 범위인데 **현재 전 SPA 유저에게 라이브**(GP 과금 미부착·워터마크) | 1차엔 잠근다 |
| 숏판·롱판 | `gallari_enabled` 플래그로 이미 잠김 ✅ | 유지 |

⚠️ **순차 오픈용 플래그가 `gallari_enabled` 하나뿐이다.** 아래 Phase 0에서 범용 플래그를 먼저 깐다.

### 🟡 E. 운영·법무

- `RESEND_API_KEY` 미등록 → **버그봇 이메일 경보 off**(웹푸시만 동작)
- **심사용 계정 GC 지급 없음** → 신규계정 GC 0이라 심사자가 AI 창작에서 막힌다 (거절 사유)
- 출금: 최소 20만원·수익배분 75%는 확정이나 **원천징수 3.3% 실무 미확정**
- 예측: 무상재화(GP)라 안전 설계지만 **스포츠 여론형 법률자문 미완**
- `rate_limit_email_sent=30/시간` — 런칭 스파이크엔 부족할 수 있음

## 3. 로드맵

### Phase 0 — 배관 (8/26 ~ 9/1, 1주) · 사용자에게 안 보임

목표: **돈 받을 수 있는 상태 + 순차 오픈 스위치**

1. **범용 피처 플래그** — `app_settings`에 `features` 한 행(jsonb)으로 통합.
   클라 공용 헬퍼 `GALLA_feature('calls')` → 통화·창작에이전트·라이브·숏판을 한 스위치로.
2. **결제 배관 마감**
   - `20260825100000_iap_refund_revoke.sql` 적용 → `revoke_gc_topup` 생성
   - `verify-iap`(구글 분기) 재배포 + `store-notify` 최초 배포
   - 스토어 시크릿 8개 등록 (사장님 계정 작업)
   - **Apple Small Business Program 가입 확인** — 미가입이면 여기서 멈추고 먼저 신청
3. **웹 PG 결정** — 토스페이먼츠 계약 착수(법인 있음). 웹 결제는 스토어 심사와 무관하게 먼저 열 수 있는 유일한 수익 경로다.
4. **반쯤 켜진 기능 잠금** — 통화·창작에이전트 플래그 off

### Phase 1 — 웹 소프트런칭 (9/1 ~ 9/14, 2주) · **여기가 진짜 승부처**

앱스토어보다 먼저. 심사 없이 고칠 수 있고, 34명→유의미한 활동으로 만드는 게 스토어 등록보다 시급하다.

1. **웹 PG 라이브** → 갈라 최초 매출
2. **시딩**: `docs/seed-posts.md` 기준 이슈 20~30개 수동 투입. 봇 이슈만 있으면 신규 유저가 5초 만에 이탈한다.
3. **초대 루프 가동**: `galla.im/?ref=<코드>` (+1000GP), `/match` 궁합 미끼 SNS 배포
4. **목표 수치(이게 게이트)**: 주간 활성 30명 · 주간 댓글 100건 · D7 리텐션 20%
   → **미달이면 Phase 2로 넘어가지 않는다.** 빈 앱을 스토어에 올리면 리뷰 별점이 먼저 죽는다.
5. `RESEND_API_KEY` 등록 → 경보 이중화

### Phase 2 — Google Play (9/15 ~ 9/28, 2주) · 심사 1~3일, $25

Play를 먼저 하는 이유: 등록비 싸고, 심사 짧고, TestFlight 블로커가 없다.

1. 개발자 등록 → 앱 생성 → `docs/store-listing.md` 복붙
2. 피처그래픽 제작 + 스크린샷 8장 촬영
3. **Play Billing 플러그인 부착** → `GALLA_verifyPurchase('google', …)` 연결 (브리지는 이미 있음)
4. `gc_products`에 android 6행 insert
5. **비공개 테스트 트랙 → 지인 20명 → 프로덕션**
6. 첫 실결제 1건 + **환불 1건 왕복 검증**(store-notify가 실제로 회수하는지)

### Phase 3 — iOS App Store (9/29 ~ 10/19, 3주)

1. **TestFlight 블로커 해결이 선행조건** — 새 빌드번호로 재업로드, 안 되면 Apple 개발자 지원 티켓
2. `aps-environment=production` + `APNS_ENV=production`
3. StoreKit 2 부착 + `gc_products` ios 6행
4. **심사 대비 3종**
   - 심사용 계정에 GC 선지급 (없으면 창작 기능에서 막혀 거절)
   - anti-steering 최종 점검: 앱 내 원화·웹 유도 문구 0 (`js/charge.js` isApp 가드는 이미 있음)
   - UGC 요건: 신고·차단·EULA — 다 있으나 심사노트에 위치를 명시
5. 제출 → 심사 (첫 제출은 리젝 1회를 기본 가정)

### Phase 4 — 2차 기능 (10월 이후)

`galla-launch-phases` 확정대로 **창작 에이전트(종량과금 `20260824100000_gc_metered.sql` 포함)**.
그 외 대기열: 통화 정상화, 라이브 난장, 숏판·롱판 공개, 안드로이드 FCM 콜푸시.
