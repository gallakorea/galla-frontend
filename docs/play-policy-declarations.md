# Play 콘솔 제출 문구 모음 (안드로이드 출시)

> 26.9.21 작성. Play Protect 유해앱 판정 위험 전수 점검(광고 SDK 0개·원격 로딩 없음 확인) 후,
> 콘솔에서 **그대로 복사해 붙일 수 있게** 정리한 답변들이다.
> 선언과 실제 동작이 어긋나면 광고 사기와 무관하게 앱이 내려가므로, 코드를 바꾸면 이 문서도 같이 고친다.

---

## 1. 위치 권한 선언 (Location permissions declaration)

**묻는 것**: 정밀 위치(ACCESS_FINE_LOCATION)가 왜 필요한가

**답변 (한국어)**

> 갈라는 두 기능에서만 위치를 사용하며, 둘 다 사용자가 직접 버튼을 눌렀을 때 그 순간에만 요청합니다.
>
> 1. **위치 공유** — 1:1 대화(갈라톡)에서 사용자가 「위치 보내기」를 누르면 현재 위치를 상대에게 한 번 전송합니다. 약속 장소를 알리는 용도라 건물 단위 정확도가 필요합니다.
> 2. **주변 맛집** — 사용자가 「내 주변」을 누르면 가까운 순으로 정렬합니다. 이 기능은 대략 위치(COARSE)만 사용합니다.
>
> 백그라운드 위치는 수집하지 않습니다. 위치 이력을 저장하지 않으며, 위치 정보를 광고나 제3자 제공에 사용하지 않습니다.

**답변 (영문, 필요 시)**

> GALLA uses location in two features only, each triggered by an explicit user action.
>
> 1. **Location sharing** — In 1:1 chat, tapping "Send location" transmits the current location once to the recipient. Building-level accuracy is required so the recipient can find the meeting point.
> 2. **Nearby restaurants** — Tapping "Near me" sorts places by distance. This feature uses coarse location only.
>
> We do not collect background location, do not store location history, and never use location for advertising or third-party sharing.

**체크 항목**
- 백그라운드 위치 사용: **아니오**
- 위치 데이터 판매·공유: **아니오**

## 2. 데이터 안전 (Data safety) 핵심 답변

| 항목 | 답변 | 근거 |
|---|---|---|
| 전송 중 암호화 | 예 | 전 구간 HTTPS/WSS |
| 삭제 요청 경로 | `https://galla.im/settings` | 계정 삭제 기능 내장 |
| 제3자 공유 | 예(서비스 운영 목적) / 광고 목적 **아니오** | Supabase·Cloudflare |
| 광고 식별자(AD_ID) | **아니오** | 광고 SDK 0개 |
| 위치 | 수집(대략+정밀), 앱 기능 목적 | 위 1번 |
| 마이크 | 수집(통화 중 실시간), 저장 안 함 | 면상톡·육성톡 |
| 카메라 | 수집, 사용자가 올린 것만 저장 | 영상통화·클립·사진 업로드 |
| 사진/동영상 | 수집(사용자 업로드) | 글·댓글 첨부 |

⚠️ **광고를 도입하는 날 같이 고쳐야 하는 것**: 광고 식별자 「예」로 변경, `AD_ID` 권한 선언 추가,
개인정보처리방침에 광고 식별자 수집 명시. 이걸 빠뜨리면 업데이트가 반려된다.

## 3. 심사 메모 (App access / Review notes)

> **테스트 계정이 필요합니다.** 갈라는 대부분의 기능이 로그인 후 동작합니다.
> 계정: (Play 콘솔 「앱 액세스 권한」에 별도 입력)
>
> **결제에 대하여**: 앱 내 모든 유료 결제는 Google Play 결제를 사용합니다.
> 앱 안에서 외부 결제 수단을 안내하거나 유도하지 않습니다.
>
> **사용자 제작 콘텐츠**: 모든 게시물·댓글에 신고와 차단 기능이 있습니다.
> 차단 시 해당 사용자의 콘텐츠가 즉시 숨겨집니다.
>
> **예측 기능에 대하여**: 갈라의 예측은 현금 가치가 없는 포인트(GP)로만 참여합니다.
> GP는 판매하지 않으며(출석·활동으로만 획득), 현금이나 현금성 재화로 환전할 수 없고, 사용자 간 양도도 불가합니다.
> 도박·사행성 요소가 아닙니다.

## 5. 앞으로 지킬 것 (점검에서 나온 원칙)

1. **광고 SDK 를 넣지 않는다.** 불가피하면 AdMob 하나만, 미디에이션 금지.
   (피키캐스트가 내려간 원인은 자체 코드가 아니라 타사 광고 SDK 였다)
2. **원격 로딩(server.url)·OTA 를 쓰지 않는다.** 로컬 번들만 로드한다.
3. **난독화·패커를 쓰지 않는다.** 코드가 투명해야 자동 분석이 정상 앱으로 판정한다.
4. **GP 판매 금지 원칙을 지킨다.** 이 선을 넘으면 도박 앱 심사 대상이 되고,
   한국에서는 사행산업 규제까지 얽힌다. 되살리자는 얘기가 나오면 법률 검토가 먼저다.
5. **신고 처리 이력을 남긴다.** UGC 앱은 Play Protect 가 아니라 신고 대응 속도로 내려간다.
