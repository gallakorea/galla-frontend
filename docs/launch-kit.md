# GALLA 런칭 킷 — 사람 모으기 실행 플레이북 (2026-07)

원칙: **사이트 홍보가 아니라 "이슈"를 뿌린다.** 커뮤니티는 광고를 자르지만 논쟁거리는 퍼진다.
공유 단위는 항상 콘텐츠(이슈/예측) 링크 — OG 카드·엣지 메타가 이미 세팅돼 있어 링크만으로 카드가 예쁘게 뜬다.

---

## 1. 커뮤니티 시딩 (효과 1순위)

### A형 — 이슈 미끼형 (권장, 잘 안 잘림)
> 제목: 이거 여러분은 어느 쪽임? "전세금 국가 관리 추진, 집주인 사용 불가"
>
> 본문: 오늘 이거 보고 지인들이랑 싸웠는데 진짜 반반 갈리더라.
> 찬반 실시간으로 갈리는 거 보니까 신기함 → (이슈 링크)
> 지금 찬성 52% vs 반대 48%던데 여기 사람들은 어느 쪽?

- 매일 그날 가장 뜨거운 갈라 이슈 1개를 골라 위 포맷으로.
- 커뮤별 어투 맞추기(디시=반말 드립, 클리앙/더쿠=존대, 블라인드=직장인 톤).
- **각 커뮤 홍보 규정 확인 필수. 도배 금지 — 커뮤당 하루 1개.**

### B형 — 직접 소개형 (스타트업/IT 커뮤 전용)
> 이슈로 겨루는 실시간 여론 배틀 플랫폼을 만들었습니다 — 갈라(galla.im)
> 진영을 골라 참전하면 댓글에 HP가 붙어서 공격/방어로 전투하고, 갈라예측에서
> GP 걸고 결과 맞히고, AI가 여러 언론을 종합한 갈라뉴스까지. 피드백 환영합니다.

- 대상: 디스콰이엇, 커리어리, GeekNews, 서핏, 인디해커 카톡방 등 — 여기는 직접 소개가 문화.

### 채널 우선순위
1. **디스콰이엇·GeekNews** (메이커 소개 — B형, 초기 피드백+아군 확보)
2. **에펨코리아·디시 이슈갤·더쿠·네이트판** (이슈 미끼 — A형, 트래픽 볼륨)
3. **블라인드** (직장·경제 이슈 A형)
4. **카톡 오픈채팅** (정치/주식/이슈 방 — 이슈 링크 공유)

## 2. SNS 운영 (계정 이미 있음: 인스타 galla.kr · 틱톡 galla.korea · X gallakorea)

### 콘텐츠 포맷 (주 5회, 하루 1개)
- **찬반 투표 카드**: 그날 핫이슈 1줄 + "당신의 선택은?" → 스토리 투표 스티커 → "실시간 전황은 프로필 링크"
- **전황 중계 릴스**: 갈라 투표 바가 실시간으로 갈리는 화면 녹화 15초 + 자막 "지금 52:48로 뒤집힘"
- **예측 결과 발표**: "어제 예측 적중자 N명, 최고 배당 ×3.2" (숫자가 후킹)

### 캡션 템플릿
> 🔥 오늘 대한민국이 갈라진 이슈
> "___________________"
> 👍 찬성 __% vs 👎 반대 __%
> 당신의 한 표가 전황을 바꾼다 → galla.im
> #갈라 #실시간여론 #찬반토론 #오늘의이슈

### X(트위터)
- 이슈 제목 + 현재 % + 링크만. 짧을수록 리트윗 잘 됨.
- 실시간 트렌드 키워드가 갈라 이슈와 겹치면 즉시 그 이슈 링크 트윗.

## 3. 친구 초대 루프 (구축 완료 — quest.html)
- 초대한 사람 **+1,000 GP** / 가입한 친구 **+500 GP** (일 10건 캡)
- 링크: `galla.im/?ref=코드` — 퀘스트 페이지에서 복사/공유
- 초기엔 지인 20~30명에게 직접 초대 링크 → 씨앗 유저 확보가 최우선

### 초대 메시지 템플릿 (카톡용)
> 나 요즘 이거 함 ㅋㅋ 이슈마다 찬반으로 붙는 여론 배틀 앱인데
> 내 링크로 가입하면 게임머니 500GP 줌 → galla.im/?ref=XXXXXX
> 들어와서 나랑 반대편 서봐

## 5. 측정 (이미 구축됨)
- **GA4**: 유입 채널·페이지 (관리자 대시보드 🌐 카드)
- **관리자 대시보드**: DAU/실시간 접속/가입
- 시딩 글에는 `?utm_source=fmkorea` 식 파라미터를 붙이면 GA에서 채널별 성과 구분 가능
