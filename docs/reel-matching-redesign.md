# 릴스 매칭 재설계 (다음 세션 시작점)

> 사장님 결정(2026-08-15): 누적된 레이어를 패치하지 말고 **매칭 단계를 새로 설계**한다.
> 시작 전에 사장님이 주는 **정답표**를 받고, 그것을 통과해야만 완성으로 친다.

## 왜 새로 짜는가

오늘 매칭에 다섯 겹이 쌓였고, 층끼리 서로 덮어쓰며 새 오류를 만들었다:

1. 규칙(글자·개념) 점수 → 2. 의미 임베딩 → 3. 2단계 최적배정(헝가리안)
→ 4. 편집장 AI 검수 → 5. 명시 핀(PINS)

여기에 조립부·워커까지 각자 재배치를 해서, "매칭이 맞게 정해도 화면은 다르다"가 반복됐다.
(조립·워커의 재배치는 이미 금지시킴 — 커밋 `bacfeff12`, `da066cd20`)

## 새 설계 (한 줄기)

```
대본 문장  →  [샷 요구서]  →  [클립 카탈로그]  →  1:1 배정  →  타임라인
             문장당 1개        클립당 1개(캐시)     단순 규칙      그대로 렌더
```

- **샷 요구서**: 문장마다 "무엇이 보여야 하는가"를 한 줄로. (이미 `shotList()` 있음)
- **클립 카탈로그**: 클립마다 {음식/장소 이름, 동작, 샷크기, 쓸만함}. **캐시로 고정**(이미 `clip_analysis`).
- **배정**: 요구서 ↔ 카탈로그를 **이름 우선**(빈대떡=빈대떡)으로 맞추고, 남는 것만 유사도로.
  검수·핀·최적배정 같은 겹은 **두지 않는다**. 한 곳에서만 결정한다.
- 조립·워커는 이미 "매칭 결과 그대로" 상태 — 유지.

## 완성 기준 (정답표)

사장님이 아래 형식으로 5~6줄만 주면, 그걸 자동 테스트로 만든다.

```
문장                                  →  기대 화면
남대문시장 안쪽 골목 부원면옥입니다        →  시장 골목 or 가게 외관
1960년부터 이어온 평양냉면 노포인데       →  가게 간판
2층 입구가 좁아서 모르면 그냥 지나칩니다   →  계단
매콤한 무침에 소스를 부어 비비면          →  제육무침
빈대떡은 겉은 바삭 속은 촉촉하고요        →  빈대떡
물냉면은 슴슴한 육수에 계란이랑 편육까지   →  물냉면
백년가게 선정된 집 남대문 오면 무조건 저장 →  남대문 거리 or 가게 외관
```

→ 이걸 통과 못 하면 "완성"이라고 보고하지 않는다.

## 오늘 확보된 것(유지할 것)

- **결정적 실행**: 같은 입력 → 같은 결과(2회 연속 동일 확인). 편집장 검수 OFF, TTS 캐시, 클립 판정 캐시.
- **마 제거**: 음성의 쉬는 구간 삭제 + 자막·컷 타이밍 동반 압축(31초→24초).
- **테이크 추출**: 흔들림·초점나감 구간 폐기, 안정된 3~6초만 사용(원본 122초 중 78초 채택).
  걷는 움직임(계단)은 살리고 카메라 휙 돌림만 폐기.
- **미리보기 2탭 교체**: `op: cuts/swap/approve` + `friend.js` UI. 마지막 1~2컷은 사람이 고친다.
- 컷 중복 0, 색보정 OFF(사장님 지시).

## 검증 규칙(반드시)

- AI가 붙인 라벨(캡션)로 판단하지 말 것. **렌더된 프레임을 뽑아 눈으로 확인**한다.
- 유리한 한두 지점만 보지 말고 정답표 전 항목을 본다.
