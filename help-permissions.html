🎙 마이크·카메라가 안 될 때

삐삐 녹음, 음성 메시지, 육성톡·면상톡이 안 되면 대부분 권한 한 곳이 막혀 있어요. 내 기기에 맞는 방법을 골라주세요.

지금 내 상태

정밀 진단 실행 (3초 녹음 테스트)

안드로이드 · 크롬

팝업이 아예 안 뜬다면 전역 스위치가 꺼진 경우가 가장 많아요.

  1. 크롬 오른쪽 위 ⋮ → 설정
  2. 사이트 설정 → 마이크 (통화하려면 카메라도 동일하게)
  3. 맨 위 스위치를 “사이트에서 마이크를 요청할 수 있음”으로
  4. 아래 차단됨 목록에 galla.im이 있으면 눌러서 액세스 재설정
  5. 갈라로 돌아와 다시 녹음 → 팝업이 뜨면 [앱 사용 중에만 허용]
💡 더 빠른 길: 갈라 화면에서 주소창 왼쪽 슬라이더 모양 아이콘 → 맨 아래 권한 재설정.

안드로이드 · 홈 화면 앱

설치한 앱에는 주소창이 없어서, 권한을 휴대폰 설정에서 켜야 해요.

  1. 홈 화면의 갈라 아이콘을 꾹 누르기
  2. ⓘ 앱 정보 → 권한
  3. 마이크(그리고 카메라) → 앱 사용 중에만 허용
  4. 목록에 마이크가 없으면 “권한 더보기 / 모든 권한”을 눌러보세요
⚠️ 기기에 따라 설치한 앱에서는 마이크가 아예 제공되지 않기도 해요. 그럴 땐 크롬으로 galla.im을 열어 녹음하면 정상 동작합니다.

아이폰 · 사파리

사파리는 마이크 권한을 탭 단위로만 기억해서, 새로 열 때마다 다시 물어봐요. 아래로 고정할 수 있어요.

  1. 설정 앱 → Safari
  2. 아래로 내려 마이크 (통화는 카메라도) 선택
  3. 허용으로 변경
  4. 또는 갈라 화면에서 주소창의 ぁA → 웹사이트 설정 → 마이크 허용
✅ 가장 확실한 방법 — 갈라를 홈 화면에 추가하세요. iOS 16.4부터 홈 화면 앱은 권한이 앱에 저장돼서 한 번만 물어봅니다.
공유 버튼 ⬆︎ → 홈 화면에 추가.

아이폰 · 홈 화면 앱

홈 화면 앱은 권한이 저장돼요. 한 번만 허용하면 계속 유지됩니다.

  1. 갈라 앱에서 녹음을 눌러 팝업이 뜨면 허용
  2. 이미 거부했다면 설정 → 아래로 내려 갈라 찾기
  3. 마이크(그리고 카메라) 스위치를 켜기
  4. 목록에 갈라가 없으면 앱을 지웠다가 다시 홈 화면에 추가
💡 iOS 16.4 미만이면 홈 화면 앱에서 마이크가 안 돼요. 사파리에서 galla.im을 열어 사용해주세요.

카톡·인스타 안에서 열었을 때

앱 안에 들어있는 간이 브라우저는 마이크가 막혀 있어요. 설정으로도 못 바꿉니다.

  1. 오른쪽 위 ⋮ 또는 ⋯ 누르기
  2. 다른 브라우저로 열기 / Chrome으로 열기 / Safari로 열기
  3. 거기서 녹음하면 정상 동작해요

녹음은 되는데 소리가 안 담겨요

권한은 정상인데 무음만 들어오는 경우예요. 아래 순서로 확인해보세요.

  1. 마이크 구멍을 손이나 케이스가 막고 있지 않은지 (폰 아래쪽)
  2. 녹음기·통화·회의 앱을 최근 앱에서 밀어 완전히 종료
  3. 블루투스 이어폰·스피커를 잠시 끄기 (그 기기 마이크로 녹음될 수 있어요)
  4. 그래도 안 되면 폰 재시작
그래도 안 되면 를 눌러주세요. 어떤 기기·브라우저인지 자동으로 함께 전송돼서 빠르게 도와드릴 수 있어요.
